# FoxBridge Privacy Policy

© 2026 Jennifer K. Mellen

FoxBridge collects no data. The Firefox add-on talks only to the FoxBridge program on your own computer (127.0.0.1:47821). Page content, screenshots and logs go to that local program only when Claude asks for them, and are never sent to any server run by FoxBridge or its author. Nothing is stored, sold or shared.
